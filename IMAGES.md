# AceVisitor image plan

The paths below are local files under `public/`; for example,
`/images/home/hero-dashboard.webp` maps to
`public/images/home/hero-dashboard.webp`. Keep the generated image at the
recommended dimensions and export it as WebP. The interface preserves each
image's existing aspect ratio and displays the current branded gradient
placeholder until the corresponding file exists and loads successfully.

All prompts share these art-direction requirements: premium enterprise visitor
management brand; deep navy `#041E26` environment and interface surfaces; crisp
cyan highlights and restrained lime accents; modern, calm, trustworthy, and
realistic; refined natural lighting; polished but plausible corporate
workplaces; no visible third-party logos, watermarks, garbled text, or
illegible interface labels. For product UI images, create clean realistic
interface mockups with legible, minimal labels and believable data rather
than abstract decorative dashboards.

## Alt text and implementation mapping

Each listed asset is passed to the existing `ImageSlot` together with its
content-provided alt text. The carousel selects its path and alt text from
`lib/content/gallery.ts`. If an image file is absent or fails to load,
`components/ui/ImageSlot.tsx` displays the existing branded gradient
placeholder with that same alt text.
